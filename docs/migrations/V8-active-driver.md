# V8: 회원당 활성 운전자 한 명 보장

운전자 등록과 탈퇴는 같은 회원 행을 잠근다. 데이터베이스도 `deleted = false`인 운전자에만 회원 ID의 유일성을 보장한다. 삭제된 운전자 이력은 유지한다.

## 적용 전 확인

운영 데이터가 있다면 먼저 다음 조회로 중복을 확인한다.

```sql
SELECT member_id, array_agg(driver_id ORDER BY driver_id) AS driver_ids, count(*) AS active_count
FROM drivers
WHERE deleted = false
GROUP BY member_id
HAVING count(*) > 1;
```

결과가 있으면 V8은 원본 행을 변경하지 않고 오류로 중단한다. ID가 크거나 작다는 이유만으로 보존할 운전자를 자동 선택하지 않는다. 회원·차량 정보와 평점 이력을 검토해 보존할 등록을 결정하고, 운영 담당자가 중복 등록을 정리한 뒤 위 조회가 빈 결과인지 확인한다. 정리 전에는 운전자 등록 요청을 잠시 차단해 중복이 다시 생성되지 않게 한다.

PostgreSQL의 V8 마이그레이션은 트랜잭션으로 실행된다. 중복 오류를 해결한 뒤 마이그레이션을 다시 실행한다. 실패를 숨기기 위한 `baseline`이나 중복 데이터 자동 삭제를 사용하지 않는다.

## 적용 후 확인

동일 회원의 활성 운전자를 둘 이상 저장할 수 없어야 한다. 삭제된 운전자와 새 활성 운전자는 함께 보존할 수 있다. 기존 차량 번호의 전체 행 UNIQUE 제약은 유지되므로, 삭제된 이력에 있는 차량 번호를 새 등록에 재사용하는 정책은 이번 변경에 포함하지 않는다.
